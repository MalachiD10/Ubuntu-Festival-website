# Ubuntu Festival Website

A community event website designed to provide information, handle registrations, and manage enquiries for the Ubuntu Festival.

## About
The Ubuntu Festival celebrates community, culture, and unity. 
This website serves as the main hub where attendees can learn about the event, register to attend, and get in touch with organizers.

## Features
- **Event Information**: Dates, venue, schedule, performers, and festival highlights
- **Online Registrations**: Visitors can sign up to attend the festival
- **Enquiries & Contact**: Form for questions, sponsorships, and vendor applications
- **Responsive Design**: Works on desktop, tablet, and mobile

## Tech Stack
- HTML5
- CSS3


## How to Run Locally
1. Download and unzip `WPR project.zip`
2. Open `index.html` in your browser
3. Or host it using any web server like XAMPP, Live Server, or GitHub Pages
